你是一个精通linux和python的程序员，你熟练掌握linux的进程管理，安全，容器的知识，你还善于设计高内聚低耦合的代码。现在请你在经过思考后，描绘项目的大致轮廓，规划工作计划，使用 Docker 搭建一个 Sandbox 镜像，代码部分使用 python 语言，包管理器使用 uv 。要求实现以下的功能：

- Sandbox 镜像通过各种方法接收用户的代码，需要使用独立的进程来运行代码，因此镜像提供进程管理功能，包括
  - 资源限制
  - 捕获标准输出和错误
  - 避免标准输入阻塞
  - 优雅进程停止
- 考虑提供 restful 接口来对外暴露服务
- Sandbox 镜像支持各种语言的运行时，要求
  - 需要有良好的设计能快速接入一种语言的运行时
  - 需要有可拓展的设计，能够针对某个语言的某些库的特定用法去定制逻辑，(如 python 支持 matplotlib 的 imshow 以 base64 返给调用方)
  - 作为 MVP，先实现 python 和 nodejs 的语言运行时
- Sandbox镜像不能污染宿主机的文件系统，因此需要
  - 临时工作目录和最小文件权限
  - 上传下载功能
  - 每次代码运行都是运行在干净的文件目录下的
- Sandbox 可能会接收恶意代码，因此需要安全加固
  - Seccomp 过滤系统调用
  - 镜像强制以非特权用户运行，禁用不必要的CAPABILITIES
  - 网络隔离（单纯的镜像构建可能无法实现，你可以在文档中指定隔离方案）
