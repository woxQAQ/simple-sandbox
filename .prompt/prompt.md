你是一个精通linux和go的程序员，你熟练掌握linux的进程管理，安全，容器的知识，你还善于设计高内聚低耦合的代码。现在请你在经过思考后，描绘项目的大致轮廓，规划工作计划，使用 Docker 搭建一个 Sandbox 调度系统，代码部分使用 go 语言。要求实现以下的功能：

- 一个容器管理器，负责管理沙盒容器的生命周期，包括启动、停止、删除等操作
  - 兼容 docker/containerd/oci-d 等 容器运行时
  - 检查指定的语言镜像是否存在，不存在则拉取
  - 启动/停止/删除沙盒容器，获取沙盒容器的 stdout 和 stderr。
  - 支持用户自定义超时时间，避免任务死循环。
  - 能够配置沙盒容器的资源限制，包括 CPU 和内存，需要有机制避免过多的沙盒任务请求，导致主机资源不够。
  - 能够挂载容器卷，支持挂载宿主机文件系统到容器内。
  - 支持配置容器的安全配置，用户未指定的情况下使用默认配置。
  - python运行时需支持 matplotlib 的 imshow 以 base64 返回调用方。具体语言运行时以自构建容器的方式实现。你需要在 docker/{lang} 目录中实现一个 Dockerfile 用于构建语言运行时镜像。
- 一个 apiserver，暴露 restful API，根据请求调用容器管理器启动沙盒容器,并在沙盒容器内执行用户的代码，在 docker/ 下构建 apiserver 的镜像
- 公共库的代码需要放在 pkg/ 下,你需要为项目实现一个统一的日志，并且在关键调用路径上打印必要的日志。
- 在 .github/ 下构建 github action 用于构建 docker 中的镜像并推送。对于语言运行时镜像，当且仅当 docker/{lang} 目录下存在 Dockerfile 时，才会触发构建，当且仅当 docker/{lang} 下的文件发生变化时，才触发构建。
